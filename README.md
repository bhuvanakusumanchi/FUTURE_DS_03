# Marketing Funnel & Conversion Performance Analysis

## Project Overview
This project analyzes marketing funnel and customer conversion performance using Power BI. The objective was to identify customer conversion patterns, contact performance, monthly trends, and customer characteristics affecting conversions.

## Tools Used
- Power BI
- Dataset: Bank Marketing Dataset
- Data Analysis & Visualization

## Dashboard Features
- Customer Conversion Overview
- Lead Conversion Funnel
- Conversion by Contact Type
- Monthly Conversion Performance
- Customer Conversion by Age Group
- Housing Loan Impact on Conversion

## Key Insights
1. Overall customer conversion rate is low, with most customers not converting.

2. Cellular contact method performed better than telephone contact.

3. Customers in the 26–35 and 36–50 age groups showed higher conversion.

4. Conversion performance changed across months, showing timing impacts results.

5. Housing loan status affected customer conversion behavior.

## Recommendations
- Focus more on cellular-based marketing campaigns.
- Target high-converting age groups (26–50).
- Improve low-performing monthly campaigns.
- Personalize customer targeting strategies.
- Reduce funnel drop-offs through better follow-up.
